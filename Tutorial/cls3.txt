Cisco Packet Tracer – Class 3 Notes
1. Static Routing Topology
4 Routers (Cisco 1841)
4 Switches (Cisco 2960)
8 PCs (2 PCs per network)
Each network has a different IP address.
Routers are used to connect different networks.
2. Devices & Cables
Router: Cisco 1841
Switch: Cisco 2960
End Devices: PCs
PC ↔ Switch: Copper Straight-Through
Switch ↔ Router: Copper Straight-Through
Router ↔ Router: Serial DTE (Red Cable)
3. Add Serial Ports to the Router
Open Router → Physical.
Turn Off the router.
From the left panel, drag WIC-2T into an empty slot.
Turn the router On.
Wait for the router to finish booting, then click OK.
Repeat for all routers.
4. Configure End Devices
Go to Desktop → IP Configuration.
Set a Static IP Address.
Set the Subnet Mask.
Set the Default Gateway (Router interface IP).
5. Test the Local Network
Open Desktop → Command Prompt.
Use the ping command to test communication between PCs in the same network.
Reply from... → Connection successful.

Note: At this stage, only devices within the same network can communicate. Static routes between routers will be configured next.
